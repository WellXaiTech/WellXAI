# Commit messages: no AI co-author trailer

Do not add a `Co-Authored-By: Claude ...` (or any AI-tool) trailer to
commit messages in this repo. The owner does not want an AI identity
showing up in the GitHub Contributors list — that trailer's email is
what causes it. Write commit messages as normal, without that line.
