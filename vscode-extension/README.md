# ChatGiZa for VS Code

Chat with GiZa directly inside VS Code to build, edit, and debug real code in your open workspace.

## Setup

1. Run **ChatGiZa: Sign In** from the Command Palette (`Ctrl/Cmd+Shift+P`).
2. It opens `chatgiza.com/vscode-auth` in your browser -- sign in there and generate a token.
3. Paste the token back into the prompt in VS Code.

## Use

Open the Chat view (`Ctrl/Cmd+Alt+I`) and start a message with `@chatgiza`, e.g.:

> @chatgiza add a dark mode toggle to the settings page

GiZa can read and search your workspace, and propose file changes or terminal commands -- you always get a
confirmation prompt naming the exact file or command before anything actually happens.

## Sign out

Run **ChatGiZa: Sign Out** from the Command Palette.
